使い方の流れ

研究上の選択から確認可能な結果へ

コーディング支援エージェントが手順を読み、テンプレートを調整してスクリプトを実行します。解析計画、コード、結果、レビューを後から確認できます。

  1. 1

    内容を定めて承認

    研究内容を定め、レシピまたはスキルを選び、科学的な選択を確認します。

  2. 2

    調整して実行

    エージェントが利用者の環境でコードを生成・実行し、主にMNE-Pythonを使います。

  3. 3

    確認して再実行

    保存された出力、図、方法の記述、確認記録をレビューし、記録された解析を再実行します。

独自の解析を設計 既存の解析をレビュー 保存済みの解析を再実行

実行例

内容を確認できるN400解析

ERP COREの参加者20名

固定Pythonチュートリアルで、意味プライミングのレシピからエポック、参加者別平均、統計、図、方法の記述を保存します。保存済み平均から群統計を再計算するか、生のEEGを使わずに公開配列から図を再作成できます。

保存済み結果から図を再作成 全手順を見る 保存済みの数値結果

固定チュートリアルには解析環境とArialまたはHelveticaが必要です。全手順の実行にはEEGデータも必要ですが、エージェントやモデルのアカウントは使いません。 データの準備 · 図に使うフォント.

エージェントとレシピを使う
  1. 研究課題。 非関連の標的語が、関連する標的語よりも陰性のN400を誘発するかを検討します。
  2. 研究者による承認。 イベントラベル、CPz/Cz/Pz、300–500 ms、クリーニングと統計を確認し、判断の難しいICA成分をレビューします。
  3. 生成したコードと結果。 エージェントがスクリプトを書いて実行し、条件別平均、統計、図、方法、レビュー記録を保存します。

記録されたエージェントの例はICA、local AutoReject、1024 Hzを使いました。固定チュートリアルはICAを省略し、256 Hzを使うため、結果は別に扱います。

記録された結果と適用範囲

CPz/Cz/Pzの300–500 msの解析では、参加者ごとに各条件60試行を保持しました。「非関連条件−関連条件」の振幅は−2.957 µV（SEM 0.466）で、一つのクラスタがp = .0002でした。保存済みの実行では、再実行によりtマップ、クラスタマスク、p値、置換帰無分布の値が完全に一致しました。小さな公開配列から図を再作成することもできます。

この記録された分岐では、ICAと振幅による除外を省略しています。実行例の20名は元データの40名より少なく、ROIの検定は過去の全チャネル認証とは別です。頭皮分布図は記述的なもので、クラスタ結果から各電極・時点を特定することはできません。v0.3.2以降に追加したこの例は、LLMの成功率、時間短縮、未使用データでの性能、臨床的有効性を測るものではありません。

以前のN100・Flankersの例

これらの単一参加者の例はv0.3.2以降に修正しました。図、スクリプト、元の計画、有意・非有意の結果、修正記録は過去の例で確認できます。母集団の効果やLLMによる時間短縮を示すものではありません。

AEAを使う

レシピから始め、科学的な選択を明示する

Git、Conda、ログイン済みのCodex CLIまたはClaude Codeを用意してください。以下は main を使う手順で、v0.3.2以降の修正を含みます。

ターミナルで入力
git clone https://github.com/dengzhe-hou/auto-eeg-analysis.git
cd auto-eeg-analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent codex
codex
Codex内で入力
$eeg-recipe n400-semantic --data projects/my-study

git clone https://github.com/dengzhe-hou/auto-eeg-analysis.git
cd auto-eeg-analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent claude
claude
Claude Code内で入力
/eeg-recipe n400-semantic --data projects/my-study

解析環境を有効にして、リポジトリのルートから起動します。対応データを projects/my-study/raw/ に置き、パラダイムに合うレシピを選んでください。ERP COREでは、コピーして使えるN400の説明と承認プロンプトに従い、既存のデータ配置を保ってください。

検出されたデータを確認し、実行前に解析計画を承認してください。この経路の標準監査用にレビュー用モデルを設定します。Claude Codeで解析する場合も必要です。

セットアップガイドでは、共通Python環境、データ形式、研究用ディレクトリ、出力を説明しています。Windowsと追加依存関係はプラットフォーム対応を確認してください。固定リリースを選ぶこともできます。

EEGLABの File > Manage EEGLAB extensions で AEA を検索し、0.1.3をインストールしてください。拡張の設定ガイドに従って、AEAのソースフォルダとコーディングクライアントを接続します。Windowsでは、最初のレポートを作る手順でクライアントの導入、実行ファイルのパス、メニュー設定、レポートの開き方を確認できます。実際のCodex・Claudeクライアントを使ったWindows MATLAB経路を固定合成データで確認し、独立した結果の確認と再実行を完了しています。

EEGLAB 0.1.3プレビューでは、Python/MNEなしで研究用フォルダを準備し、範囲を限定したERP平均値、図、レポートを作成するMATLABネイティブ設定ガイドを追加しました。対応するソースとプラグインを組み合わせてください。旧0.1.2 ZIPはMNE経路を使います。

ホームページとREADMEは英語・簡体字中国語・日本語に対応しています。詳細ガイド、スキル・レシピのソース、図中の文字、EEGLABのメニュー、固定レポートのテンプレートは現在も主に英語です。エージェントとの研究内容の相談には中国語や日本語も使えます。
