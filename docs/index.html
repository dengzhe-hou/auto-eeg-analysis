A numerically certified core

Evidence, with its scope attached.

Full certification record ↗

The certified core covers ERP amplitudes and cluster statistics in selected configurations, plus spectral band power checked against an independent Welch implementation. Other checks have their own stated scope; certification does not apply to every option or generated workflow.

MNE-Python is the primary backend. EEGLAB and FieldTrip comparisons test selected capabilities and numerical conventions.

Read the benchmark record ↗
Methods text from the run.

Reads pipeline logs and writes a COBIDAS-MEEG paragraph. Every number from disk, not memory. No other EEG tool does this.

Built to be shared

A method is more useful
when someone else can run it.

AEA builds on the ARIS architecture and EEG domain knowledge, with MNE-Python for computation. AEA is to MNE what HuggingFace is to PyTorch.
