# Source Sans 3

The homepage uses the upright variable Source Sans 3 font, distributed under the SIL Open Font License in [OFL.txt](OFL.txt).

Source: [Google Fonts source file](https://github.com/google/fonts/blob/main/ofl/sourcesans3/SourceSans3%5Bwght%5D.ttf), retrieved on 2026-11-04. The font is served locally with the site; Chinese and Japanese pages retain their system font stacks.
