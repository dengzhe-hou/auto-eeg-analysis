03

Get started

Packages and versions ↗

Use your own coding client and analysis environment.

Python / MNE

The PyPI preview creates a new project with the AEA resources. Python 3.10+ and an existing MNE environment are required. The default package does not install the scientific dependencies.

Full setup and dependencies ↗

In your terminal
python -m pip install auto-eeg-analysis==0.3.3rc2
aea-eeg init ./my-eeg-study --agent codex
cd my-eeg-study
codex
Inside the coding client
$eeg-recipe n400-semantic --data .
In your terminal
python -m pip install auto-eeg-analysis==0.3.3rc2
aea-eeg init ./my-eeg-study --agent claude
cd my-eeg-study
claude
Inside the coding client
/eeg-recipe n400-semantic --data .

Place compatible data in my-eeg-study/raw/, then start your signed-in coding client in that project. Choose the recipe for your paradigm and approve the plan before computation. Configure the reviewer for the audit stage.

Install from a Git checkout
In your terminal
git clone https://github.com/dengzhe-hou/Auto-EEG-Analysis.git
cd Auto-EEG-Analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent codex
codex

Using MATLAB / EEGLAB?

Install AEA 0.1.3 through the EEGLAB extension manager, or use the MATLAB toolbox preview. The native MATLAB route covers explicit ERP means from existing epochs. The broader library primarily uses MNE-Python.
