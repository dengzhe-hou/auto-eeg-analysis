## Coverage and provenance

The published evidence archive is Zenodo DOI [10.5281/zenodo.24012489](https://doi.org/10.5281/zenodo.24012489), version 2026-11-06. It holds release-specific numerical records, the 600-session study, ERP development records and the final ERP comparison. This extended-records package is a later compilation. It does not assert that the 8 November repair study was already in that archived version.

source-data contains the saved 600-session and final ERP tables plus summary records, metrics and frozen protocols for the earlier and repaired 1800-session continuous comparisons. These are existing results. No sessions, grades or intervals were regenerated. Full 1800-session first-delivery artifacts remain a separate pending archive item. Summary CSV files do not replace those original artifacts.

The retained source-files note is a dated index. Some paths describe author working directories or older figure versions. This compact package relocates the extended supplement and selected summary data. Full recorded programs and intermediates remain in the separately cited versioned archives. It is not a standalone figure-reproduction bundle. The original wording remains preserved for traceability.

No raw third-party EEG, restricted SEED-V recordings, private access links, API credentials or client account configuration are included. Provider data access rules remain in force. AEA code and recipes retain their existing licenses and provenance.

## Reuse

Use the fixed repository commit containing this directory when citing or retrieving these records. The separate published Zenodo version retains its own DOI. A Zenodo update for this compilation can be prepared without overwriting the published version.
