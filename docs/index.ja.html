はじめに

パッケージとバージョン ↗

利用中のクライアントと解析環境で始められます。

Python / MNE

PyPIプレビュー版から、AEAリソースを含む新しいプロジェクトを作成します。Python 3.10以降と既存のMNE環境が必要です。標準パッケージは解析用の依存関係をインストールしません。

導入と依存関係の説明 ↗

ターミナルで入力
python -m pip install auto-eeg-analysis==0.3.3rc2
aea-eeg init ./my-eeg-study --agent codex
cd my-eeg-study
codex
クライアント内で入力
$eeg-recipe n400-semantic --data .
ターミナルで入力
python -m pip install auto-eeg-analysis==0.3.3rc2
aea-eeg init ./my-eeg-study --agent claude
cd my-eeg-study
claude
クライアント内で入力
/eeg-recipe n400-semantic --data .

対応データをmy-eeg-study/raw/に置き、そのプロジェクトでログイン済みクライアントを起動します。パラダイムに合うレシピを選び、計算前に解析計画を承認してください。 監査段階のレビュー用モデルを設定してください。

Gitソースから導入
ターミナルで入力
git clone https://github.com/dengzhe-hou/Auto-EEG-Analysis.git
cd Auto-EEG-Analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent codex

MATLAB / EEGLABを使う場合

EEGLABの拡張マネージャーでAEA 0.1.3を導入するか、MATLABツールボックスのプレビュー版を利用できます。MATLABネイティブ経路は、既存エポックから明示したERP平均値を計算します。より広いライブラリは主にMNE-Pythonを使います。

04

確認されている範囲

検証範囲 ↗

数値比較は、記録された設定と保存された出力に対応します。

ERP振幅
一部の出力をMNE-BIDS-Pipeline、EEGLAB、FieldTripと比較。
クラスタ統計量
一部の観測tマップとクラスタ分割をFieldTripと比較。
スペクトルパワー
独立したWelch実装による帯域パワーの確認。

検証は対象の出力と設定に限定され、生成されるすべてのワークフローを認証するものではありません。
