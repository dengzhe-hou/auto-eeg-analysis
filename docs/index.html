How it works

From study choices to inspectable results

A coding agent reads the procedures, adapts templates, and executes scripts. The analysis plan, code, results, and review remain available to inspect.

  1. 1

    Specify & approve

    Define the study, select a recipe or skills, and confirm the scientific choices.

  2. 2

    Adapt & execute

    The agent generates and runs code in your environment, mainly with MNE-Python.

  3. 3

    Inspect & replay

    Review saved outputs, figures, methods text, and checks; replay the documented analysis.

A worked example

An N400 analysis you can inspect

20 ERP CORE participants

Follow a fixed Python tutorial from a semantic-priming recipe to saved epochs, participant averages, statistics, figures, and methods text. Recompute group statistics from the saved averages, or replot the public arrays without raw EEG.

Replot saved results Open the full tutorial Saved numerical results

The fixed tutorial needs the analysis environment and Arial or Helvetica; full execution also needs the EEG data. It uses no agent or model account. Data setup · Figure fonts.

Use the recipe with a coding agent
  1. Research request. Test whether unrelated target words evoke a more negative N400 than related targets.
  2. Researcher approval. Confirm event labels, CPz/Cz/Pz, 300–500 ms, cleaning and statistics; review ambiguous ICA components.
  3. Generated code and results. The agent writes and runs scripts, retaining condition averages, statistics, figures, methods and review records.

The recorded agent example used ICA, local AutoReject and 1024 Hz sampling. The fixed tutorial omits ICA and uses 256 Hz; its results are separate.

Recorded results and scope

The CPz/Cz/Pz analysis at 300–500 ms retained 60 trials per condition for each participant. Unrelated minus related amplitude was −2.957 µV (SEM 0.466), with one cluster at p = .0002. In the saved run, replay reproduced t maps, cluster masks, p values, and permutation null values exactly. The figure can also be regenerated from the compact public arrays.

This documented branch omits ICA and amplitude rejection. The 20-person worked-example cohort is smaller than the 40-person source cohort, and its ROI test is separate from the historical all-channel certification. Scalp maps are descriptive; clusters do not localize each electrode or time point. This post-v0.3.2 example does not measure LLM success rate, time savings, held-out performance, or clinical efficacy.

Earlier N100 and Flankers examples

These single-participant examples were corrected after v0.3.2. Figures, scripts, original plans, positive and null results, and correction records remain accessible through the historical examples. They do not establish population effects or LLM-related speedup.

Methods text

AEA reads pipeline logs and writes a COBIDAS-MEEG paragraph. Every number from disk, not memory. No other EEG tool does this.

Use AEA

Start with a recipe. Keep the scientific choices visible.

Install Git, Conda, and a signed-in Codex CLI or Claude Code client. Commands below use main, including fixes added after v0.3.2.

In your terminal
git clone https://github.com/dengzhe-hou/auto-eeg-analysis.git
cd auto-eeg-analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent codex
codex
Inside Codex
$eeg-recipe n400-semantic --data projects/my-study

Run from the repository root with your analysis environment active. For compatible data, place files in projects/my-study/raw/ and choose a recipe matching your paradigm. For ERP CORE, use the copy-ready N400 brief and approval prompt to preserve the existing data layout.

Review the detected data and confirm the analysis plan before execution. Configure the reviewer for this route's default audit, including when Claude Code runs the analysis.

The setup guide covers the shared Python environment, data formats, study directories, and output files. See platform support for Windows and optional dependencies, or choose a fixed release.

Using EEGLAB? The preview extension adds a Tools menu to export the current dataset, start an AEA study, and open its report. MATLAB desktop validation is pending.
