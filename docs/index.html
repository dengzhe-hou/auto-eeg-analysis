Automated EEG Analysis

AEA is an open library of 22 EEG analysis skills and 10 recipes. Use Codex CLI or Claude Code to generate and run analysis code with MNE-Python, keeping the plan, code, results, figures, methods text, and review together.

A skill provides reusable instructions for analysis, reporting, or review. A recipe combines skills and parameters for a particular paradigm, such as an oddball task. The library has a numerically certified core; coverage depends on the output and configuration.

Example

ERP CORE Flankers

Subject-001: stimulus-locked N2, response-locked conflict, and frontal theta. Two of the three tests pass the Bonferroni-adjusted cluster threshold (p < .05 / 3).

Recorded results

Minimum cluster p values: N2 .0588 (d = −0.062), response-locked conflict .0006 (d = −0.316), and theta .0002 (d = 0.295). All retained trials enter the analysis; 5,000 label permutations preserve block and target side. Theta uses joint frequency × time × electrode clusters.

The response contrast is incompatible minus compatible, separate from the 14-participant error-minus-correct ERN benchmark. The run record gives the trial counts, assumptions and results.

The original pipeline reported 94.6 s; the corrected downstream run took 12.60 s from saved epochs. These measure different stages and do not establish complete-pipeline or LLM-related speedup. The historical figure remains available.

MNE sample: auditory versus visual N100

One participant, 61 complete stimulus cycles (244 trials). The analysis pairs auditory and visual responses within each cycle and uses six electrodes approximating the planned ROI, with 3–27 mm location differences.

Auditory minus visual: −1.54 µV, paired-cycle Cohen's dz = −0.462. One cluster passed the p < .05 threshold (p = .0004; 5,000 permutations). The original target-epoch retention was 100% (289 / 289). The corrected analysis excludes 45 target trials in incomplete cycles, separately from artifact rejection.

The fixed presentation order confounds condition with position within a cycle. The sign-flip test assumes independent, symmetric cycle differences; it does not establish a population effect. See the run record. The historical figure remains available.

These single-participant corrections were made after v0.3.2. Group validations are documented separately in the benchmark record.

Installation

Install Git, Conda, and a signed-in Codex CLI or Claude Code client first. Choose a recipe that matches your paradigm. The example below uses compatible Flankers data; replace ern-flankers with the recipe for your study.

Keep the repository root as your working directory. Put your study's data in projects/my-study/raw/ before running the recipe, or follow the data setup guide for another layout.

In your terminal 
git clone https://github.com/dengzhe-hou/auto-eeg-analysis.git
cd auto-eeg-analysis
conda env create -f environment.yml
conda activate aeais
python tools/install_skills.py --agent codex
codex
Inside Codex 
$eeg-recipe ern-flankers --data projects/my-study

Usage

Run a recipe eeg-recipe
Choose a recipe for your paradigm, check its data requirements, confirm the plan, and run the specified analysis.
Custom analysis eeg-pipeline
Define the claims, contrasts, and design. Combine the relevant skills with a frozen analysis plan and recorded outputs.
Review an analysis eeg-audit
A fresh reviewer checks whether the plan, statistics, figures, and methods support the reported findings.

Validation

The numerically certified core covers ERP amplitudes and cluster statistics in selected configurations, plus spectral band power checked against an independent Welch implementation. Other checks have their own stated scope; certification does not apply to every option or generated workflow.

MNE-Python is the primary backend. EEGLAB and FieldTrip provide independent comparisons and selected alternative paths, with the numerical conventions documented for each capability.

Methods text

AEA reads pipeline logs and writes a COBIDAS-MEEG paragraph. Every number from disk, not memory. No other EEG tool does this.

Project

AEA builds on the ARIS architecture and EEG domain knowledge, with MNE-Python for computation. The source code and development history are on GitHub.
