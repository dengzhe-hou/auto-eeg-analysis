# eeg-bids: raw → BIDS-EEG

## Context: $ARGUMENTS

## Constants

- **BACKEND = `mne_bids`** — Python backend for BIDS conversion.
- **OVERWRITE = `false`** — refuse to clobber an existing `bids/` unless explicitly told via `— overwrite`.
- **OUTPUT_DIR = `bids-stage/`** — BIDS-formatted output directory.
- **BIDS_VERSION = `1.9.0`** — target BIDS specification version.

## Required Inputs

Before running, these must exist:

1. `DATASET_BRIEF.md` — for paradigm, condition marker codes, demographics.
2. `raw/` directory — containing raw EEG files (`.set`, `.vhdr`, `.edf`, `.bdf`, `.fif`, `.cnt`, `.mff`).
3. `ENVIRONMENT.json` — to verify `mne_bids` is available.

## Phases

### A. Scan raw files

1. Read `DATASET_BRIEF.md` for paradigm + condition marker codes + demographics.
2. Glob `raw/` for all supported EEG file formats:
   - BrainVision: `*.vhdr` + `*.vmrk` + `*.eeg`
   - EEGLAB: `*.set` (+ optional `*.fdt`)
   - EDF/BDF: `*.edf`, `*.bdf`
   - MNE-FIF: `*.fif`, `*_raw.fif`
   - Neuroscan: `*.cnt`
   - EGI/MFF: `*.mff` (directory format)
3. For each raw file, extract metadata via MNE-Python:
   ```python
   import mne
   raw = mne.io.read_raw_<format>(filepath, preload=False)
   info = raw.info
   # Extract: n_channels, sfreq, ch_names, ch_types, meas_date
   events = mne.find_events(raw, stim_channel='auto')
   # Extract: unique event codes, event counts
   ```
4. Build a scan table: `subject_id | file | format | n_channels | sfreq | n_events | event_codes`.
5. Verify scan results against `DATASET_BRIEF.md`:
   - Expected number of subjects matches files found.
   - Expected event codes are present in each file.
   - Channel count matches declared montage.
6. Write `bids-stage/RAW_SCAN_REPORT.md` with the scan table and any discrepancies.

### B. Build BIDS structure

For each subject's raw file:

1. **Create BIDSPath**:
   ```python
   from mne_bids import BIDSPath, write_raw_bids
   bids_path = BIDSPath(
       subject=subject_id,       # e.g., '01'
       session=session_id,       # if multi-session, else None
       task=task_name,           # from DATASET_BRIEF paradigm
       run=run_id,               # if multiple runs
       datatype='eeg',
       root=bids_root            # e.g., '<project-dir>/bids-stage/'
   )
   ```

2. **Extract and map events**:
   ```python
   events, event_id = mne.events_from_annotations(raw)
   # Or: events = mne.find_events(raw, stim_channel=stim_ch)
   # Map event codes to BIDS-friendly names from DATASET_BRIEF
   event_id = {'target': 1, 'standard': 2, 'deviant': 3}  # from DATASET_BRIEF
   ```

3. **Write BIDS**:
   ```python
   write_raw_bids(
       raw=raw,
       bids_path=bids_path,
       events=events,
       event_id=event_id,
       overwrite=OVERWRITE,
       format='BrainVision',     # output format (BrainVision is most portable)
       verbose=False
   )
   ```

4. **Required BIDS files** (auto-generated by `write_raw_bids`, verify they exist):

   **Dataset-level** (one per dataset):
   - `dataset_description.json` — name, BIDS version, license, authors, references.
   - `participants.tsv` — subject demographics (participant_id, age, sex, handedness).
   - `participants.json` — column descriptions for `participants.tsv`.
   - `README` — dataset description.
   - `CHANGES` — version history.

   **Subject-level** (per subject):
   - `sub-<id>/eeg/sub-<id>_task-<task>_eeg.<ext>` — raw data file.
   - `sub-<id>/eeg/sub-<id>_task-<task>_eeg.json` — sidecar with acquisition parameters:
     ```json
     {
       "TaskName": "auditory_oddball",
       "EEGReference": "FCz",
       "SamplingFrequency": 512,
       "PowerLineFrequency": 50,
       "SoftwareFilters": {"HighpassFilter": {"CutoffFrequency": 0.1}},
       "EEGChannelCount": 64,
       "EOGChannelCount": 2,
       "ECGChannelCount": 0,
       "Manufacturer": "BrainProducts",
       "ManufacturersModelName": "actiCHamp Plus",
       "CapManufacturer": "EasyCap",
       "CapManufacturersModelName": "actiCAP snap"
     }
     ```
   - `sub-<id>/eeg/sub-<id>_task-<task>_events.tsv` — event timing with columns: `onset`, `duration`, `trial_type`, `value`, `sample`.
   - `sub-<id>/eeg/sub-<id>_task-<task>_events.json` — column descriptions.
   - `sub-<id>/eeg/sub-<id>_task-<task>_channels.tsv` — channel table (name, type, units, status).
   - `sub-<id>/eeg/sub-<id>_task-<task>_electrodes.tsv` — electrode positions (name, x, y, z).
   - `sub-<id>/eeg/sub-<id>_task-<task>_coordsystem.json` — coordinate system description.

5. **Build `participants.tsv`**:
   ```python
   # From DATASET_BRIEF demographics or auto-extracted from files
   # Required columns: participant_id
   # Recommended: age, sex, handedness
   import pandas as pd
   participants = pd.DataFrame({
       'participant_id': [f'sub-{sid}' for sid in subject_ids],
       'age': ages,       # from DATASET_BRIEF or 'n/a'
       'sex': sexes,      # 'M', 'F', or 'n/a'
       'handedness': hands # 'R', 'L', 'A', or 'n/a'
   })
   participants.to_csv(bids_root / 'participants.tsv', sep='\t', index=False)
   ```

6. **Write `dataset_description.json`**:
   ```python
   import json
   desc = {
       "Name": dataset_name,           # from DATASET_BRIEF
       "BIDSVersion": "1.9.0",
       "License": "CC0",               # default; user can override
       "Authors": authors,             # from DATASET_BRIEF or ask user
       "DatasetDOI": "",               # fill if known
       "GeneratedBy": [
           {"Name": "auto-eeg-analysis", "Version": "0.1.0"},
           {"Name": "MNE-BIDS", "Version": mne_bids.__version__}
       ]
   }
   with open(bids_root / 'dataset_description.json', 'w') as f:
       json.dump(desc, f, indent=2)
   ```

   > **Provenance is not just for the root.** This `GeneratedBy`/`SourceDatasets`
   > record describes only the raw BIDS dataset. Do not stop here: every
   > downstream AEA stage should emit its own derivative subtree (see
   > "BIDS-Derivatives chain" below) so the chain stays machine-traceable.

### C. Validate

1. **MNE-BIDS tree check**:
   ```python
   from mne_bids import print_dir_tree
   print_dir_tree(bids_root)
   ```

2. **BIDS validator** (if available):
   ```bash
   # Node.js BIDS validator
   bids-validator <bids_root> --verbose
   # Or Python bids-validator
   python -m bids_validator <bids_root>
   ```
   - If `bids-validator` is not installed, log a warning and proceed with MNE-BIDS checks only.
   - Parse validator output: count errors vs warnings.
   - **Errors**: must be fixed before proceeding. Common issues:
     - Missing `dataset_description.json` → create it.
     - Missing `*_events.tsv` → extract from raw annotations.
     - Invalid `PowerLineFrequency` → set from `— powerline:` argument or DATASET_BRIEF.
   - **Warnings**: log but do not block.

3. **Internal consistency checks**:
   - Every subject in `participants.tsv` has a corresponding `sub-<id>/` directory.
   - Every `sub-<id>/` directory has at least one `_eeg.*` file.
   - All `_eeg.json` sidecars have `TaskName`, `EEGReference`, `SamplingFrequency`, `PowerLineFrequency`.
   - All `_events.tsv` files have required columns (`onset`, `duration`, `trial_type`).
   - Event codes in `_events.tsv` match those declared in DATASET_BRIEF.

4. Write `bids-stage/BIDS_VALIDATION.md`:
   - Validator version + pass/fail.
   - Error count + list.
   - Warning count + list.
   - Tree structure printout.

### D. Write report

Write `bids-stage/BIDS_REPORT.md`:
- Number of subjects converted.
- BIDS directory structure.
- Per-subject file inventory.
- Validation result (pass/fail, error count).
- Any manual fixes required.

Write `bids-stage/BACKEND_RESOLUTION.md`:
- `mne_bids` version.
- `mne` version.
- BIDS validator version (if available).
- Python version.

## Failure modes

| Symptom | Action |
|---|---|
| Raw file format not recognized | Stop. List supported formats. Ask user for correct format or conversion. |
| `mne_bids` not installed | Stop. Print install instructions: `pip install mne-bids`. |
| Event codes mismatch DATASET_BRIEF | Stop. Show detected vs expected codes. Ask user to update DATASET_BRIEF or provide marker mapping. |
| `bids/` already exists and `OVERWRITE=false` | Stop. Ask user to pass `— overwrite` or delete manually. |
| BIDS validator reports errors | List errors. Attempt auto-fix for common issues. If unfixable, stop and report. |
| Missing electrode positions | Warn. Use standard montage from MNE if channel names match 10-20 system. |
| Mixed file formats in `raw/` | Handle each format separately. Log format per subject. |

## Domain Knowledge

### Pernet et al. 2019: EEG-BIDS specification
- The EEG extension to BIDS (Brain Imaging Data Structure) standardizes how EEG data are organized.
- Key principle: all metadata that a researcher needs to analyze EEG data should be machine-readable in the BIDS sidecar files.
- `PowerLineFrequency` is REQUIRED (50 Hz in Europe/Asia, 60 Hz in Americas).
- `EEGReference` is REQUIRED — the online reference electrode during acquisition.
- Event files (`_events.tsv`) must use onset in seconds (not samples) relative to recording start.
- Cite: Pernet, C. R., et al. (2019). EEG-BIDS, an extension to the brain imaging data structure for electroencephalography. Scientific Data, 6, 103.

### BIDS-Derivatives chain (Pernet et al. 2019; MNE-BIDS-Pipeline)
- Raw-to-BIDS conversion is only the first link. The BIDS spec defines a
  `derivatives/` convention so that every processed product carries its own
  provenance, and EEG-BIDS adopts it. Emit a **derivatives chain**, not a
  one-shot conversion.
- Each downstream AEA stage (`eeg-preprocess`, `eeg-ica`, `eeg-epoch`, ...) should
  write into its own derivative subtree, e.g.
  `bids-stage/derivatives/<stage>/`, with a **per-derivative
  `dataset_description.json`** that records:
  - `"DatasetType": "derivative"`,
  - `"GeneratedBy": [{"Name": "<stage>", "Version": "<version>"}]` — the actual
    pipeline step and version that produced this subtree (not just the root
    `auto-eeg-analysis` entry),
  - `"SourceDatasets": [...]` — pointing at the dataset (raw or upstream
    derivative) it consumed.
  ```python
  deriv_root = bids_root / 'derivatives' / stage_name
  deriv_desc = {
      "Name": f"{dataset_name} — {stage_name}",
      "BIDSVersion": BIDS_VERSION,
      "DatasetType": "derivative",
      "GeneratedBy": [{"Name": stage_name, "Version": stage_version}],
      "SourceDatasets": [{"URL": "../.." }],   # raw root or upstream derivative
  }
  ```
- Payoff: provenance is machine-traceable from any derivative back to raw, the
  whole run is re-ingestible by standard BIDS apps, and the flat
  `REPRO_RECEIPT` is brought into line with the standard derivatives spec —
  this is the layout MNE-BIDS-Pipeline already produces.
- Cite: Pernet, C. R., et al. (2019). EEG-BIDS, an extension to the brain imaging data structure for electroencephalography. Scientific Data, 6, 103 (Derivatives extension); MNE-BIDS-Pipeline (mne.tools/mne-bids-pipeline).

### Appelhoff et al. 2019: MNE-BIDS
- MNE-BIDS automates BIDS conversion from MNE-Python Raw objects.
- `write_raw_bids()` handles format conversion, sidecar generation, and event extraction.
- `BIDSPath` is the central object for constructing BIDS-compliant file paths.
- `read_raw_bids()` reads BIDS-formatted data back with all metadata attached.
- `print_dir_tree()` visualizes the BIDS directory for quick verification.
- Supports all major EEG formats via MNE-Python readers.
- Cite: Appelhoff, S., et al. (2019). MNE-BIDS: Organizing electrophysiological data into the BIDS format and facilitating their analysis. Journal of Open Source Software, 4(44), 1896.

### Gorgolewski et al. 2016: BIDS for neuroimaging
- BIDS was originally designed for MRI data and later extended to EEG, MEG, iEEG.
- Core principles: human-readable directory names, machine-readable JSON sidecars, TSV for tabular data.
- File naming convention: `sub-<label>[_ses-<label>]_task-<label>[_run-<index>]_<suffix>.<extension>`.
- `dataset_description.json` is the only REQUIRED file at the dataset root.
- `participants.tsv` is RECOMMENDED for subject-level demographics.
- Cite: Gorgolewski, K. J., et al. (2016). The brain imaging data structure, a format for organizing and describing outputs of neuroimaging experiments. Scientific Data, 3, 160044.
